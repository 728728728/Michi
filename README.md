# Michi

本人専用のスマホロックと、習慣をつなぎ替えるための育成RPG（iPhone・Safari で動かす Web アプリ）。

YouTube やゲームを開いた瞬間に、iPhone のショートカットのオートメーションでこのアプリへ飛ばし、60秒の「波を待つ」画面・状態に合わせた声かけ・気持ちの吐き出し・2分着手を挟む。作業した分だけ娯楽の持ち時間が貯まり、夜はスクリーンタイムで完全にロックする。

## しくみ

| 層 | 担当 |
|---|---|
| スクリーンタイム（OS） | 夜 0:00〜7:30 の完全ロック、Web の youtube.com 禁止、App のインストール禁止。パスコードはアプリが生成して封印 |
| ショートカットのオートメーション | 対象アプリを開いた → 通行証ファイルの期限を確認し、切れていれば介入画面へ。閉じた → 使った時間を精算 |
| このアプリ（Safari） | 介入画面・集中タイマー・朝の3つ・育成「時間奪還の旅」・記録・見直し日 |

ショートカットからは次の URL で呼ばれる。

- `?ev=open&app=youtube` / `?ev=open&app=game` … 対象アプリを開いた
- `?ev=closed&app=…&pass=<通行証ファイルの中身>` … 対象アプリを閉じた
- `?ev=morning` … 朝（就寝ロック明け）

通行証ファイル（iCloud Drive/Shortcuts/Michi/pass.txt）は「期限・番号・アプリ・分」の4行。介入画面で通行証を出すと `shortcuts://run-shortcut?name=Michi通行` で保存される。

## ルール

- 持ち時間：作業 2:1（1〜2週目）→ 3:1（3〜4週目）→ 4:1。休日（土日祝）は1段階ゆるい。上限は平日60分・休日90分
- 超過した分は翌日以降の借金。ショートを見たら当日の残りは没収
- 魔王軍の襲撃：5分未満の超過＝材料の一部、5分以上・ショート・無断通行・スクリーンタイムとの照合で記録外の使用＝いちばん強い装備が消える、夜のロック破り＝周回終了
- 設定を緩められるのは週1回の見直し日（初期値：日曜 19:00〜22:00）だけ

## 構成

- `index.html` / `style.css`
- `js/app.js` 画面の切り替えとショートカットからの呼び出しの受け取り
- `js/rules.js` 稼ぎ・通行証・精算・夜・見直し日
- `js/game.js` 育成（装備・シナジー・戦闘の計算・魔王軍）
- `js/sprites.js` ドット絵
- `js/screens/*.js` 各画面
- `js/version.js` バージョン（変更したら上げ、`sw.js` の `CACHE` も合わせる）

データはすべて端末の localStorage（`michi.state`）にだけ保存する。

## 開発

```bash
python -m http.server 8793 --directory Michi
```

- `_test/index.html` は時計をずらせるテスト用ページ（`sessionStorage` の `michi.test.at` に `10:00` や `2026-10-11T19:30:00` を入れて読み込む。`__skew(ms)` で進める）
- `_test/balance.mjs` はボスの HP の釣り合いを確かめるシミュレーション（`node _test/balance.mjs`）
